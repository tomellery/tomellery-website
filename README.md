# tomellery.com

Tom Ellery's personal site, served by GitHub Pages from this repository. Plain HTML, CSS and JavaScript with no build step.

## Neon Arcade (`/arcade/`)

Original browser games in the style of '80s arcade classics: Neon Snake, Brick Buster, Road Hopper, Swarm Strike, Maze Munch and Deep Driller.

- **Built from scratch.** All code, pixel art, maze and level layouts, and sounds were written for this site. Sprites are hand-written pixel maps in each game's JavaScript; sounds are synthesized live with the Web Audio API. Nothing was taken from a commercial game, ROM or emulator.
- **Our own names.** The games play like the classics but never use their trademarked names, characters' names or text.
- **Fonts:** Press Start 2P, loaded from Google Fonts under the SIL Open Font License.
- **High scores** are shared through the Cloudflare Worker in `worker/`.

## If the site ever makes money

The arcade is free, with no ads, donations or paid features. If any of that is ever added, do an IP review of the games' look first, and get advice from an IP attorney if a rights holder ever gets in touch.
